## Contributing to Docs

- Put durable knowledge in `docs/`, not only in issue comments or PR threads.
- Add new docs to this index.
- Use a status header: `Active`, `Draft`, `Idea`, or `Superseded`.
- Treat `docs/research/` and `docs/future/ideas/` as decision inputs, not current
  specifications.
- Link related issues or PRs when a doc records a decision.
- Update the matching doc when behavior, architecture, or workflow changes.
